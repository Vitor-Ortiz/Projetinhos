# Projetos para praticar

## Projeto atual: Casa do Café

Site de uma cafeteria de bairro, com páginas de início, cardápio, sobre e contato.

## Próximo exercício: Estação Verde

Uma pequena loja de plantas para apartamentos, com o mesmo escopo e nível do site atual.

- Início com destaque para plantas fáceis de cuidar.
- Catálogo com nome, preço, luminosidade e frequência de rega.
- Página Sobre contando a história da loja e seus cuidados com as plantas.
- Página Contato com horário, localização fictícia identificada como exercício e formulário visual.
- Navegação entre páginas, links de retorno e layout responsivo.

Para treinar primeiro: HTML semântico, caminhos relativos, links acessíveis e CSS Grid/Flexbox. Como desafio extra, adicionar um filtro simples por nível de luz com JavaScript.
